# Privacy

GE Trade Journal operates only inside RuneLite and writes files to the local user's `.runelite` directory. It makes **no outbound HTTP requests** and does not have a server address, token, Discord integration, or bank inventory access.

Data stored locally includes: OSRS character name as the directory name and in event metadata, GE item identifiers and optionally names, order slots, buy/sell states, requested price/quantity, cumulative filled quantity and cumulative GP, observed changes, locally generated UUIDs, and event timestamps.

The plugin never handles Jagex passwords or purchases/sales. Local files may be read by other software only if users separately configure that software; that is outside the plugin's control.
