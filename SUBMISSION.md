# Plugin Hub submission

GE Trade Journal is not published on the Plugin Hub yet.

1. Confirm [GitHub Actions](https://github.com/cowleyjosh/ge-trade-journal/actions) passes against the current RuneLite API.
2. Complete live development-client checks for buy, sell, partial fill, cancellation, slot reuse, and login/restart. Confirm the JSON files are valid.
3. Fork [runelite/plugin-hub](https://github.com/runelite/plugin-hub), add `plugins/ge-trade-journal` with the public repository URL and the exact tested commit SHA, then open a pull request.
4. Wait for RuneLite maintainer review and approval before announcing a Plugin Hub release.

See [Windows live testing](LIVE_TEST_WINDOWS.md) for the test procedure.
